# 備課卡片

自己備課用的卡片白板，用來在學校停止付費後取代 LoiLoNote 的個人備課功能。
用瀏覽器打開就能用，不需要帳號；所有資料只存在這台設備上。

## 功能

| 功能 | 怎麼用 |
|---|---|
| 文字卡 | 上方「文字卡」，或在空白處點兩下；點兩下卡片可以編輯 |
| 批次新增 | 上方「批次」：貼上一大段文字，每段（空一行分隔）變成一張卡片；直接貼上（⌘V）也可以 |
| 拖拉／縮放 | 拖拉卡片移動；拖拉空白處移動畫布；兩指捏合縮放；右下角「顯示全部」 |
| 調整大小 | 選取卡片後，拖拉右下角的圓點 |
| 連線 | 選取卡片 › 「連線」 › 點另一張卡片；點線可以改箭頭方向或刪除 |
| **拍照 › 放到畫布** | 上方「拍照」：相機開著可以連拍，每拍一張就立刻多一張卡片 |
| **拍照 › 放進卡片** | 選取卡片 › 「拍照放進」：照片會放進那張卡片裡面（卡中卡） |
| 把卡片放進卡片 | 把一張卡片拖到另一張卡片上，看到虛線框後放開 |
| 打開卡片 | 點卡片右下角的數字，或選取 › 「打開」；左上角「回上一層」 |
| 全螢幕 | 選取 › 「全螢幕」，或點兩下圖片卡；左右滑動切換下一張（投影學生作品用） |
| 裁切旋轉 | 選取圖片卡 › 「裁切旋轉」 |
| 匯出 | 上方「匯出」：存成圖片（PNG）、列印／存成 PDF、備份檔 |
| 復原／重做 | 上方按鈕，或 ⌘Z／⇧⌘Z |

## 在電腦上執行

```bash
python3 -m http.server 5180 --bind 127.0.0.1
```

然後打開 <http://localhost:5180>。

## 在 iPad 上使用

iPad 的瀏覽器只允許 **HTTPS 網址** 使用相機，所以要先把這個資料夾放到網路上（例如 GitHub Pages 或 Firebase Hosting，都是免費的靜態網站）。
放上去後，用 Safari 打開網址 › 分享 › 「加入主畫面」，就會像一般 App 一樣，沒有網路也能開。

## 資料與備份

- 筆記和照片存在瀏覽器的 IndexedDB 裡，只在這台設備上。
- 清除 Safari 網站資料，或刪掉主畫面的 App，資料就會不見。**請定期用「⋯ › 備份成檔案」存一份到雲端硬碟。**
- 備份檔（`.beike.json`）可以在別台設備用「匯入備份」打開。
- 備份檔是普通的 JSON，Claude 也可以直接產生這種檔案，讓你一次匯入整份做好的卡片。

## 程式結構

```
index.html          畫面骨架
css/style.css       樣式
js/main.js          筆記列表、工具列、鍵盤、貼上、拖放
js/view.js          畫布：卡片、拖拉、縮放、連線、卡中卡
js/camera.js        相機連拍、從相簿選
js/modals.js        對話框、全螢幕檢視、裁切旋轉
js/export.js        存成圖片、列印、備份檔
js/store.js         資料結構、復原／重做、自動存檔
js/db.js            IndexedDB
js/util.js          共用工具
sw.js               離線快取
```

之後要加「手機拍、電腦投影」的多台同步時，資料結構已經用 id 和 `updatedAt` 設計好，可以接 Firebase 或 Supabase。
