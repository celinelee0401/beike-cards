# 0001 純前端、資料只存本機的網頁 App

- 日期：2026-10-17
- 狀態：採用

## 背景

LoiLoNote 是學校付費帳號，沒有公開 API 或 MCP。老師需要一個自己能掌控、學校停止付費後也能繼續用的備課工具；目前只有一台 iPad 同時拍照與投影。

## 決定

- 做成純靜態網頁（PWA），不用框架、不用建置工具，部署在 GitHub Pages（HTTPS，iPad 才能用相機）。
- 筆記與照片存在 IndexedDB，不上傳任何伺服器；用 `.beike.json` 備份檔搬移與保存。
- 照片拍下後縮到最長邊 1600px 的 JPEG，節省空間。

## 後果

- 免費、離線可用、沒有學生資料外洩風險；repo 公開也只公開程式碼。
- 資料只在單一設備，清除 Safari 資料就會遺失，需要提醒老師定期備份。
- 以後做多台同步（手機拍、電腦投影）時，要另外加 Firebase／Supabase 之類的後端；資料結構已用 id 與 `updatedAt` 預留。
